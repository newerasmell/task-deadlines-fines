One file per language (el.yaml, hr.yaml, ...): english canonical note → local term, lowercase.

The GR and HR exports carry no English notes, so these files are built in phase 2: the AI proposes the English
canonical term and the local pairs in `pairs/` (e.g. `pairs/el-hr.yaml`, generated by `make report`) confirm it.
A term whose two translations agree with the pair is ok; the rest wait for approval in the app (docs/decisions.md #7).
