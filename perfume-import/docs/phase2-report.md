# Фаза 2: отчет от пусканията на живо

Фаза 2 (проучване, описания и ноти, запис в БД) е завършена и проверена с истинския Claude API върху 5 реални
продукта от експортите (`input/sample-5.csv`, магазини PremierParfums и Parfemija). Решенията са в `docs/decisions.md`
(#9 режими, #10 таван, #11 EAN от друг размер).

## Пускания и цена на продукт

| Пускане | Модел и настройки | Цена на продукт | Бележка |
|---|---|---|---|
| 1. Първо пускане | Opus 5.5, до 8 търсения + 8 цели страници, без лимит | **$1.17** (0.69–2.14) | 95% от цената е проучването: четене на цели страници. |
| 2. Евтин режим | Sonnet 5.5, до 3 търсения без страници, текстове през Batch API | **$0.081** (0.069–0.101) | 4/5 под тогавашния лимит $0.10. Batch частта: ~13 мин. |
| 3. Armani задълбочено | Opus 5.5, до 6 търсения + 4 страници по 6000 токена | **$0.527** | Хвана, че EAN 3614270581656 е за 60 ml; за 110 ml е 3614270581670. Официална снимка 2400×2400. |
| 4. Gucci, търсене на снимка | Sonnet, 1 търсене + 1 страница | **+$0.046** | Намери снимка от Notino; по-големият вариант е 949×1000. Общо за продукта ≈ $0.14. |

## Лимити сега
- Евтин режим: лимит $0.125, таван $0.15 (лимит + 20%). Преди всяка платена стъпка след проучването кодът проверява, че таванът няма да се надвиши; ако ще, стъпката се пропуска с обяснение в полето.
- Задълбочен режим: лимит $0.50, таван $0.60.

## Качество: Sonnet (евтин) срещу Opus
- Известните парфюми: нотите и семействата съвпадат.
- Sonnet ползва по-малко търсения, затова повече факти остават с един източник (за преглед).
- Sonnet без четене на страници не хваща несъответствие EAN ↔ размер. За това е задълбоченият режим.
- Xerjoff Accento Overdose: и двата модела дават съмнителна пирамида (евкалипт, бор). Нужна е ръчна проверка.

## Отворено
1. Когато човек приеме предложения EAN (#11), SKU-то и полетата от него трябва да се сглобят наново. Това е за Фаза 4.
2. „floral“ остана на английски в един гръцки текст. Да се добави към проверките за език или към промпта за превод.
3. amber е преведено като „ήλεκτρο“ при един продукт и като „κεχριμπάρι“ при друг. При одобрението за глосара се избира един превод (`build_glossary.py`).
4. Batch API отнема минути: при партида в приложението трябва да се показва ход на изпълнението.
5. Снимките от търговци остават за одобрение, защото не са от официалния сайт. Обработката им е Фаза 3.
